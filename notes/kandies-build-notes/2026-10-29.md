## Database changes

- **`deleted_account_files`** table (admin-only, RLS on): list of uploaded files to remove from storage after an account is deleted.
- **`delete_my_account()`** (SECURITY DEFINER, pinned search_path, signed-in only):
  - Refuses admin accounts.
  - Deletes the caller's artist profile, songs, licenses, and comments/hearts/votes/ratings on that artist; clears Spotlight and Browse video slots if they point to it.
  - Deletes the caller's comments, likes, hearts, votes, ratings, blocks and reports.
  - Keeps plays and ad clicks but removes the user link; keeps bug report text but removes user and email.
  - Records uploaded files for cleanup, then deletes the profile and the auth account.

## Lessons

- Send the file first, then the steps.
- Clear the SQL Editor before pasting a new query.
- A PL/pgSQL function can be created even if a table it uses doesn't exist; verify every dependency.
- Disabled buttons must look disabled; placeholder text must not look like an entry.
- Website changes go live on Netlify immediately; Android changes need a new .aab and Play upload.
